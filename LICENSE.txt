TT Test Tool 이용 약관

만든 곳과 쓸 수 있는 범위
TT Test Tool 은 TTStudio(티티스튜디오)에서 만들었습니다.
TTStudio가 직접 만든 앱 코드 · 화면은 TTStudio(티티스튜디오) · ttstudio.kr 의 것입니다.
앱에 포함된 TTStudio 독자 버전 차이 지식 · 절차 · 함정 모음
(이하 "앱 노하우")도 TTStudio(티티스튜디오) · ttstudio.kr 의 것입니다.
Electron 등 제3자 구성요소는 각 저작권자에게 속하고 개별 라이선스를 따릅니다.
아래의 복제 · 개작 · 역분석 제한은 제3자 라이선스가 부여한 권리를 제한하지 않습니다.
받은 사람은 자기 컴퓨터에서 플러그인 · 모드를 포팅하고 테스트하는 데
프로그램을 쓸 수 있습니다.

하면 안 되는 일
- 프로그램과 앱 노하우를 복제하거나 남에게 주거나 다시 배포하거나
  되팔면 안 됩니다.
- 앱 노하우를 뽑아내 공개하거나 다른 도구 · 문서 · 강의 자료 ·
  AI 학습 자료에 넣으면 안 됩니다.
- 프로그램을 고쳐 만든 것을 쓰거나 퍼뜨리면 안 됩니다.
- 프로그램을 디컴파일하거나 역분석하면 안 됩니다.
- 에이전트가 MCP 로 받아 간 앱 노하우에도 같은 제한이 걸립니다.
  보고서 · 제안에 인용된 앱 노하우를 모아 따로 퍼뜨리면 안 됩니다.

작업 결과와 올린 패키지
- 프로그램으로 만든 결과(포팅한 코드 · 빌드 산출물 · 테스트 케이스(TC) ·
  보고서)는 만든 사람의 것입니다. 위 제한은 프로그램과 앱 노하우에 걸립니다.
- 기능 명세서나 TC 초안을 만들면, 도구는 올린 JAR 에서 추출한 사실 ·
  클래스 요약 · 설정 파일 일부를 사용자가 고른 에이전트로 보냅니다.
  Codex 는 OpenAI, Claude Code 는 Anthropic 서비스로 사용자 본인의
  로그인을 통해 보냅니다. 그 서비스의 약관을 따릅니다.
- 올린 패키지를 분석하고 그 서비스로 보낼 권리가 있는지 확인하세요.
  다른 사람이 만든 플러그인 · 유료 플러그인은 해당 라이선스를 따르세요.
- 앱은 에이전트의 인증 파일을 읽지 않습니다.

테스트와 파일 받기
- 테스트 서버 · 클라이언트는 이 PC 에서 실행됩니다.
  마인크래프트 EULA 는 사람이 설정에서 따로 동의합니다.
  앱이 대신 동의하지 않습니다.
- Mojang · PaperMC · Fabric 의 공식 출처에서 필요한 파일을 받는 것은
  사람이 다운로드 허용을 켰을 때만입니다.
  Gradle 빌드는 필요한 의존성을 그 저장소에서 받습니다.
- 테스트 환경은 자바 프록시 설정을 닿지 않는 주소로 돌려 바깥 연결을
  줄입니다. 프록시를 따르지 않는 직접 연결까지 막지는 못합니다.
  믿을 수 없는 플러그인 · 모드는 따로 떼어 둔 PC 나 가상 머신에서 테스트하세요.

결과와 책임
- 점검 · 테스트를 통과해도 결함이 없다는 보증은 아닙니다.
  에이전트가 쓴 명세서 · TC 는 틀릴 수 있으므로 사람이 읽고 승인합니다.
- 프로그램은 있는 그대로 제공합니다.
  관련 법이 허용하는 범위에서, 만든 곳의 고의나 중대한 과실이 없는 한
  프로그램을 쓰다 생긴 데이터 손실 · 서버 손해에 책임을 지지 않습니다.
  라이브 서버에 올리기 전에 사람이 확인하세요.

업데이트와 바깥 요청
- 앱은 켤 때와 여섯 시간마다 배포 저장소(github.com/Yuupering/TT-Test-Tool)의
  새 정식 릴리스를 확인해 알림을 보여 줍니다. 사람이 업데이트를 누르면
  설치 파일을 받아 GitHub 첨부 정보와 크기·SHA-256을 확인한 뒤 설치합니다.
  설치 직전에 GitHub에서 같은 릴리스·첨부를 다시 확인하므로 인터넷 연결이 필요합니다.
  배포 서명 공개 키가 등록된 앱은 관리자 서명도 함께 확인합니다.
  GitHub 첨부 해시는 독립된 관리자 전자서명을 대신하지 않으며,
  배포 저장소와 GitHub 계정의 보안을 신뢰하는 방식입니다.
  설치 중 앱은 닫혔다가 다시 열리며 진행 중인 작업은 멈춥니다.
- 업데이트 확인과 커뮤니티 노하우 받기는 GitHub 에 요청을 보냅니다.
  앱은 사용 통계(텔레메트리)를 보내지 않습니다.
  설정의 업데이트에서 자동 확인을 끌 수 있습니다.

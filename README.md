# TT Test Tool

마인크래프트 Paper 플러그인과 Fabric 모드의 버전별 포팅, 빌드, 테스트를 돕는 Windows 데스크톱 앱입니다. TTStudio(티티스튜디오)에서 만듭니다.

**라이선스: [TTStudio 독점 이용 라이선스 (Proprietary)](LICENSE.txt)**

## 다운로드

[최신 버전 받기](https://github.com/Yuupering/TT-Test-Tool/releases/latest)

- **통합 설치 파일:** `TT-Test-Tool-<버전>-x64.exe` 하나를 받아 실행합니다. Windows x64용이며 설치 위치를 선택할 수 있습니다.
- 앱은 시작할 때와 6시간마다 GitHub의 새 정식 릴리스를 확인해 알림을 보여 줍니다. **설정 → 업데이트** 화면의 **업데이트** 버튼을 한 번 누르면 다운로드·검증·설치·앱 재시작까지 진행합니다(0.1.32부터 추가 확인 창 없음).
- 진행 중인 빌드·테스트·명세서 작업이 있으면 업데이트 버튼이 비활성화됩니다. 업데이트 중에는 새 장기 작업을 시작할 수 없습니다. 설정과 작업 데이터 위치는 유지됩니다.
- 설치 직전에 GitHub 첨부 정보와 파일 크기·SHA-256을 다시 확인하므로 인터넷 연결이 필요합니다. 자동 알림은 설정에서 끌 수 있습니다.
- 기존 0.1.30 포터블·ZIP 사용자는 통합 설치 파일을 한 번 직접 설치해 주세요. 이후 앱에서 새 버전 알림과 업데이트를 이용할 수 있습니다.
- `SHA256SUMS.txt`에는 각 다운로드 파일의 SHA-256 해시가 있습니다.

## 시작하기

1. 앱을 실행하고 이용 약관을 확인합니다.
2. **워크스페이스**에서 프로젝트를 등록하거나 버전별 작업 폴더를 만듭니다.
3. **설정 → 버전별 파일**에서 필요한 버전의 파일을 준비합니다. 테스트 서버를 실행하려면 **설정 → 테스트 서버**에서 Minecraft EULA와 다운로드 허용을 직접 확인합니다.
4. **버전별 작업 현황**에서 포팅 폴더와 빌드 결과를 확인하고, **테스트** 또는 **테스트 케이스(TC)** 화면에서 필요한 테스트를 실행합니다.

빌드와 테스트에는 대상 버전에 맞는 JDK가 필요합니다. AI 대화·명세서·TC 초안 기능에는 사용자 PC에 설치하고 로그인한 Codex 또는 Claude Code가 필요합니다. AI 기능을 실행하면 JAR에서 추출한 자료 일부가 선택한 에이전트 서비스로 전달됩니다.

이 릴리스에는 게임 서버·클라이언트 JAR, Java, 사용자 프로젝트와 테스트 데이터가 포함되지 않습니다. 점검과 빌드 통과는 실제 기능 동작을 보장하지 않으며, 신뢰할 수 있는 플러그인과 모드로 테스트해 주세요.

## 주요 기능

- 프로젝트 탐색과 워크스페이스 관리, 버전별 포팅·빌드 현황
- Paper·Fabric·Minecraft API 조회와 버전 차이 확인
- 기능 명세서와 TC 초안, 검토·승인·시나리오 연결
- 버전별 테스트와 회귀 테스트, 결과와 화면 증거
- AI 대화와 로컬 MCP 도구
- 커뮤니티 노하우 조회·검색·개인 반영과 서명된 묶음 확인

기본 등록 버전은 1.20.1·1.20.6·1.21.4·1.21.11·26.2·26.3입니다. 26.3 API 조회·포팅·Fabric 클라이언트 대응은 구현되어 있습니다. Paper 서버 테스트는 해당 버전의 서버 파일이 필요하며, 기본적으로 안정 빌드만 받습니다. 0.1.33부터 **설정 → 테스트 서버**에서 베타·알파 빌드도 직접 선택해 준비할 수 있습니다. 이는 실험 빌드 테스트 지원이며 모든 플러그인·모드의 호환성 보장은 아닙니다. Forge·NeoForge 조회는 현재 지원하지 않습니다.

# TT Test Tool

마인크래프트 Paper 플러그인과 Fabric 모드의 버전별 포팅, 빌드, 테스트를 돕는 Windows 데스크톱 앱입니다. TTStudio(티티스튜디오)에서 만듭니다.

## 다운로드

[최신 버전 받기](https://github.com/Yuupering/TT-Test-Tool/releases/latest)

- **간편 실행:** `TT-Test-Tool-<버전>-portable.exe`를 받아 실행합니다. 별도 설치가 필요하지 않습니다.
- **압축본:** `TT-Test-Tool-<버전>-x64.zip`을 폴더에 전부 풀고 `TT Test Tool.exe`를 실행합니다.
- Windows x64용입니다. 현재 이동식·압축본은 자동 앱 업데이트를 지원하지 않습니다. 새 버전은 위 릴리스 페이지에서 받습니다.
- `SHA256SUMS.txt`에는 각 다운로드 파일의 SHA-256 해시가 있습니다.

## 시작하기

1. 앱을 실행하고 이용 약관을 확인합니다.
2. **워크스페이스**에서 프로젝트를 등록하거나 버전별 작업 폴더를 만듭니다.
3. **설정 → 버전별 파일**에서 필요한 버전의 파일을 준비합니다. 테스트 서버를 실행하려면 **설정 → 테스트 서버**에서 Minecraft EULA와 다운로드 허용을 직접 확인합니다.
4. **버전별 작업 현황**에서 포팅 폴더와 빌드 결과를 확인하고, **테스트** 또는 **테스트 케이스(TC)**에서 필요한 테스트를 실행합니다.

빌드와 테스트에는 대상 버전에 맞는 JDK가 필요합니다. AI 대화·명세서·TC 초안 기능에는 사용자 PC에 설치하고 로그인한 Codex 또는 Claude Code가 필요합니다. AI 기능을 실행하면 JAR에서 추출한 자료 일부가 선택한 에이전트 서비스로 전달됩니다.

이 릴리스에는 게임 서버·클라이언트 JAR, Java, 사용자 프로젝트와 테스트 데이터가 포함되지 않습니다. 점검과 빌드 통과는 실제 기능 동작을 보장하지 않으며, 신뢰할 수 있는 플러그인과 모드로 테스트해 주세요.

## 주요 기능

- 프로젝트 탐색과 워크스페이스 관리, 버전별 포팅·빌드 현황
- Paper·Fabric·Minecraft API 조회와 버전 차이 확인
- 기능 명세서와 TC 초안, 검토·승인·시나리오 연결
- 버전별 테스트와 회귀 테스트, 결과와 화면 증거
- AI 대화와 로컬 MCP 도구
- 커뮤니티 노하우 조회·검색·개인 반영과 서명된 묶음 확인

버전별 기능과 지원 범위는 다릅니다. 현재 Forge·NeoForge 조회와 26.3 Paper 서버 실행 테스트는 지원하지 않습니다.
